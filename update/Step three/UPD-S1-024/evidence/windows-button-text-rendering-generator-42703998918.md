## Root cause

The clean Windows product-build workflow runs `python tools/generate_brand_assets.py`. The WPF color dictionary is generated by `tools/generate_brand_assets.py::_make_wpf_dictionary`. The A011 change edited only the generated output file, so the clean-build generator rewrote it without the correction.

- Move the ContentTemplate with explicit `PureWhiteBrush` text into the canonical generator.
- Ensure the tracked generated XAML is identical to a fresh generator output.
