# T0012 — گزارش اجرای واقعی

- **تلاش:** `T0012-A001`
- **وضعیت فعلی:** در حال اجرا؛ تکمیل تا دریافت نتیجهٔ CI اعلام نمی‌شود.
- **خروجی واقعی:** `docs/requirements.md` شامل ۲۰ نیازمندی شناسه‌دار، معیار پذیرش قابل‌سنجش، روش راستی‌آزمایی و ارجاع به وظایف گراف؛ `tests/test_requirements_contract.py` شامل آزمون‌های قرارداد سند.
- **بازبینی وابستگی‌ها:**
  - یال `T0011 → T0012` به `contract_or_interface_dependency` تغییر یافت و با دلیل/شواهد اعتبارسنجی شد؛ هدف و محدودهٔ ثبت‌شده در README ورودی واقعی سند نیازمندی‌هاست.
  - یال `T0010 → T0012` به `sequencing_only` تغییر یافت و با دلیل/شواهد اعتبارسنجی شد؛ ساخت قابل‌تکرار برای پیاده‌سازی و CI محصول همچنان الزامی است، اما پیش‌نیاز فنی نوشتن مشخصات نیازمندی نیست. این تغییر به معنای تکمیل T0010 نیست.
- **آزمون‌ها:** آزمون‌های جدید و graph guard باید در GitHub Actions اجرا شوند؛ نتیجه در زمان ایجاد این گزارش هنوز تأیید نشده است.
- **محدودیت:** سند، مشخصات قابل‌آزمون است و به‌هیچ‌وجه اثبات نمی‌کند که برنامهٔ WPF، برنامهٔ Android، موتور استنتاج محلی یا انتقال P2P ساخته شده‌اند.
- **گام بعدی:** بررسی workflow مربوط به commit `V 3.0.18`. فقط در صورت موفقیت همهٔ مراحل، وضعیت T0012 به `done` تغییر می‌کند.
