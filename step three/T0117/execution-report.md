- **Application protocol:** `Libp2pPeerMessageProtocol.cs` transfers complete binary messages with varint length prefixes, bounds message size before payload allocation, applies bounded queue backpressure and maps unexpected peer disconnection to I/O failure rather than a successful empty message.
- **Real integration test added:** two actual libp2p peers are created in the HostLifecycle test process; one listens on loopback and pins the expected client identity. The test checks mismatched target identity is rejected, binary payload bytes round-trip in both directions, messages over the configured 1 KiB bound are rejected, and disconnect is idempotent.
