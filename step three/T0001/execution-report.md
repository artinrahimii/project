1. tools/graph_guard.py پیاده‌سازی شد تا بلوک JSON گراف را از Markdown استخراج کند، شناسه‌ها و یال‌ها را بررسی کند، ارجاع‌های نامعتبر و چرخه‌ها را گزارش دهد، ناسازگاری شمارنده‌های تاریخچه را پیدا کند و برای هر گرهٔ done وجود خروجی واقعی، شواهد، آزمون موفق و تلاش موفق ثبت‌شده را الزامی بداند.
2. هنگام اجرای بررسی با --repo-root، ابزار وجود فایل‌های خروجی و شواهد مسیرمحور را نیز بررسی می‌کند؛ مسیر مطلق و مسیر دارای .. را برای خروجی‌ها نمی‌پذیرد.
3. tests/test_graph_guard.py شامل ۱۱ آزمون خودکار است که استخراج گراف، ساختار معتبر، شناسه‌های تکراری، یال آویزان، چرخه، اعتبارسنجی یال و ادعای تکمیل بدون شواهد را بررسی می‌کند.
4. docs/acceptance.md راه اجرای این کنترل و مرز آن را ثبت می‌کند. این کنترل به‌تنهایی اثبات‌کنندهٔ عملکرد برنامهٔ نهایی Windows/Android/P2P نیست.

## آزمون‌های واقعاً اجراشده

- python -m unittest discover -s tests -v — موفق؛ ۱۱ آزمون از ۱۱ آزمون پاس شد.
- python -m compileall -q tools tests — موفق؛ خطای کامپایل نحوی گزارش نشد.

آزمون‌های واحد از گراف‌های کوچک آزمایشی استفاده کردند. محتوای گراف آنلاین نیز جداگانه خوانده و JSON آن با موفقیت تجزیه شد؛ با این حال، اجرای CLI پایتون روی نسخهٔ زندهٔ فایل از یک checkout محلی در این نوبت انجام نشد. این محدودیت از نتیجهٔ آزمون‌های واحد تفکیک می‌شود.

## بررسی وابستگی مرتبط

یال T0001 → T0002 از لحاظ معنایی بررسی شد.
