# T0163-A029 — align the internal send future with Kotlin's Unit type

- **Base commit:** `3414506126b32ff11b9dba4ddd258b767f5b74d7` (`V 3.0.652`).
- **Production file:** `src/Client.Android/app/src/main/java/com/whitep/client/network/Libp2pInferenceRequestTransport.kt`.
- **Observed upstream contract:** the `SimpleClientHandler.writeAndFlush` API used by this adapter is compiled as `CompletableFuture<Unit>` (confirmed by the exact Android Kotlin compiler diagnostic in V 3.0.652).
- **Correction:** `InferencePeerMessageController.sendRequest` now declares `CompletableFuture<Unit>` and returns the `whenComplete` stage directly. The completion callback continues to zero the frame backing buffer after the write has completed.
