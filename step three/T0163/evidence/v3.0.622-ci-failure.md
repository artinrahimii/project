# T0163 — V 3.0.622 CI failure record and correction

- **Failure revision:** `2fc9d6f415668c6aaa7e72e01d2dbe30cf18206f` (`V 3.0.622`).
- **Failure:** Two independent tests, `classifiesBlankPromptAsPayloadRejection` and `identifiesEmptyPromptAsPayloadRejectionCause`, failed. The other two blank-prompt assertions (Rejected result and zero transport calls) passed.
- **Root cause:** The test-only `dispatcher(transport)` helper defaulted to `{ "attempt-one" }`, so both selected hosts received the same attempt ID. The production dispatcher correctly rejected duplicate attempt IDs before payload building; the blank-prompt tests therefore never reached `InferenceRequestPayloadBuilder`.
- **Correction in V 3.0.623:** The test helper now uses `UUID.randomUUID().toString()` for a unique ID per host. `rejectsDuplicateAttemptIdsBeforeSubmitting` still explicitly injects `"same-attempt"` to verify that separate guard.
- **V 3.0.623 result:** All 84 Android JVM tests passed, including the four blank-prompt preflight tests; all other required workflows passed. See `v3.0.623-ci-final.md`.
