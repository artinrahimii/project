The directory schema contains `peerId`, direct addresses, capabilities and `expiresAtUtc`; it contains no inference prompt or response fields. - **Implementation added:** an Android metadata-only `RendezvousPeerDirectoryClient` that requires HTTPS except loopback tests, disables redirects, applies 10-second connection/read timeouts, caps the response at 16 KiB, caches a directory snapshot for at most five seconds, and resolves the requested ephemeral host ID only when it exactly matches the announced `peerId`.

PeerId suffix, IP literal, port, expiry, capability count, duplicate records and address limits are checked. Expired records are ignored. QUIC metadata is validated but not selected by this TCP-only discovery component.
