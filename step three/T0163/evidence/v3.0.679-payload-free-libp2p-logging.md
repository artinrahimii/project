## Diagnostic implementation

1. `Libp2pPeerTransport` accepts an optional `ILoggerProvider`; without it, default product callers retain the previous logging configuration.
2. The Android/.NET test fixture supplies a provider that records category, level, event ID, static `{OriginalFormat}` template and exception type. It never renders formatted messages or structured argument values.
3. Diagnostic output is capped at 80 records per peer.
4. The Kotlin child-process reader captures a bounded number of `P2P_DIAG` records alongside the fixed phase markers.
5. A Python source-contract test guards the payload-free logging boundary and per-peer cap.
